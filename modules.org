** Mode/Header line

I want to generate a custom mode line. There will be differences in
the modeline dependent on whether the window is active or not.
I will use the left part of the modeline for the shared information
and the right part for the active only information. If I find that I
have too much information, I may also use the header line, however I
would rather save this for other information, such as breadcrumbs.

The shared information I need to convey is as follows:
- Buffer read only
  Should be conveyed by a lock icon
- Buffer name
  Need to decide on a maximum length of name to display. Where the
  name has to be shortened to fit, it should be expressed as shortened
  with triple dots. If possible this should come from the font as a
  single glyph.
- Modified status
  Should only apply to buffers that have
  an associated file. It can be conveyed by making the buffer name
  bold when it's modified.
- Major mode
  Use of icons from font for language as prefix to name where
  possible. Might need to create a variable that stores the lookups of
  major-modes to icons.
- Git branch
- envrc status

The active window information will show:
- Date/Time
- Battery status
- Power status
- Audio volume

      "Like `with-temp-buffer', but always propagate `process-environment'.
  When that var is buffer-local in the calling buffer, it is not
  propagated by `with-temp-buffer', so we explicitly ensure that

      (transient-compile--log "Running command: %s" command)

                (cons "LC_ALL=C" process-environment))
               (exit-code
                (process-file-shell-command command nil (current-buffer) nil)))
          (transient-compile--log "Command finished with status %s" exit-code)
