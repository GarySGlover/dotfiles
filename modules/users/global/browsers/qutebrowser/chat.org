*** I use nix flake, could I add qutebrowser to the inputs at the root flake.nix so that it manages the versions and updates?

Great question! In Nix flakes, inputs are typically used for whole
packages, modules, or sources you want precise control over, not for
individual system packages like =qutebrowser= (which is already
available in the Nix package set).

*What you can do:*

- *To pin a specific qutebrowser version:*
  - Add a pinned Nixpkgs input to your flake.
  - Reference =pkgs.qutebrowser= from your pinned Nixpkgs input anywhere you need qutebrowser (in system/user configs).
- *To use the latest qutebrowser:*
  - Just use your existing Nixpkgs source; updates happen when you update the flake lock.

*Example flake.nix snippet:*
#+begin_src nix
inputs = {
  nixpkgs.url = "github:NixOS/nixpkgs/nixos-unstable";
  # Optionally more inputs...
};

outputs = { self, nixpkgs, ... }@inputs:
let
  system = "x86_64-linux";
  pkgs = import nixpkgs { inherit system; };
in {
  homeManagerModules.default = { ... }: {
    programs.qutebrowser.enable = true;
    home.packages = with pkgs; [
      bitwarden-cli
      # more packages
    ];
  };
}
#+end_src

*If you want an /unreleased/ version of qutebrowser (e.g., from its GitHub repo):*
- You can add a flake input that fetches the qutebrowser repo and build from source,
- But for most users, the above method (pinning nixpkgs) is sufficient and much simpler.

*Summary:*
- You don’t need to add =qutebrowser= as a flake input, but you can tightly control its version by pinning nixpkgs with your desired package version.
- Just reference =pkgs.qutebrowser= in your configs; Home Manager/NixOS/system will get the correct version from your chosen Nixpkgs input.

*** I don't want to do it for the whole of qutebrowser, just for the scripts

Great clarification! If you only want to fetch and version-control the *qutebrowser userscripts* (like =qute-bitwarden=), you can add the scripts repo as a flake input (or fetch them as a source), independently from the main qutebrowser package. Here’s how you can do that using a flake input:

---

*** 1\. Add userscripts repo as a flake input

In your =flake.nix=:

#+begin_src nix
inputs = {
  nixpkgs.url = "github:NixOS/nixpkgs/nixos-unstable";
  # Add the qutebrowser repo for scripts only (not as a flake)
  qutebrowser-src = {
    url = "github:qutebrowser/qutebrowser";
    flake = false;
  };
};
#+end_src

---

*** 2\. Reference the script you want

In your =outputs=, reference the specific script file you want, e.g., =misc/userscripts/qute-bitwarden=:

#+begin_src nix
outputs = { self, nixpkgs, qutebrowser-src, ... }: {
  # ... your usual outputs ...

  homeManagerModules.default = { config, ... }: let
    qute_bitwarden = "${qutebrowser-src}/misc/userscripts/qute-bitwarden";
  in {
    # ... other HM config ...
    home.file.".local/share/qutebrowser/userscripts/qute-bitwarden".source = qute_bitwarden;
  };
};
#+end_src

---

*** 3\. Summary

- This approach *versions and updates the script* independently of the qutebrowser package.
- To update: run =nix flake update= and rebuild.
- It works for any scripts or files in the qutebrowser repo.

*Common causes:*

  =HTTPS_PROXY="http://yourproxy:port" bw login=

- Try running =bw login --api-url https://api.bitwarden.com= (rarely necessary, mostly for self-hosted instances, but sometimes helps).

- Try running with =DEBUG=* bw login= for more error output.

Here’s how to set custom QtWebEngine flags in your qutebrowser configuration with Nix Home Manager:

#+begin_src nix
programs.qutebrowser = {
  enable = true;
  settings = {
    "qt.args" = [ "disable-features=PermissionElement" ];
  };
};
#+end_src

*Explanation:*
- The =settings= attrset lets you specify any qutebrowser setting.
- For =qt.args=, supply a /list of strings/ (as above).

*If you’re using =extraConfig=:*
You could use:
#+begin_src nix
programs.qutebrowser = {
  enable = true;
  extraConfig = ''
    config.set("qt.args", ["disable-features=PermissionElement"])
  '';
};
#+end_src
Either approach works—pick the one matching your style!
